# RB Express – Website Documentation

**Live URL:** https://train-portfolio.netlify.app/\
**Owner:** Rahul Brahmbhatt\
**Type:** Interactive Developer Portfolio

## Overview

RB Express is a creative, single-page portfolio website built around a train journey concept. Visitors explore different sections as railway stations, guided by a character named Chotu.

## Website Sections

1. **Home:** Introduction, professional title and call-to-action.
2. **About:** Professional background and expertise.
3. **Experience:** Career timeline and achievements.
4. **Skills:** Technical skills categorized by technology.
5. **Projects:** Featured projects with external links.
6. **Education:** Academic qualifications and certifications.
7. **Contact:** Contact information and social links.
